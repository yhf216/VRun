# Upstream attribution

VRun is derived from [iOSRealRun-cli](https://github.com/iOSRealRun/iOSRealRun-cli), baseline 1710c72a60a704996bcf7d7b5e5f92f49687af39.

- Upstream Git history and the MPL-2.0 license are retained.
- vrun/coordinates.py adapts the coordinate conversion from upstream tools/run.py.
- Windows device tools, developer disk images and HNroute.txt originate from upstream.
- [iOSRealRun-cli-17](https://github.com/iOSRealRun/iOSRealRun-cli-17) (MPL-2.0) informed the RSD / DVT location workflow. The independent GPL-3.0-or-later helper uses pymobiledevice3.
- VRun adds a desktop interface, adaptive themes, route visualization, device workflow, running statistics, distance reminders and a Windows installer.

Original project credits include iOSFakeRun, libimobiledevice and Nuitka. Third-party licenses and sources are listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
